Stellar Global Supplies

Building a connected SaaS ecosystem — and migrating it from AWS to Cloudflare

The problem

Stellar Global Supplies needed more than a website — they needed an operating system for their business: a way to run analytics, quoting, workflows, advertising, order management, billing, and AI tooling as one connected ecosystem instead of disconnected point solutions. The original infrastructure was built on AWS, which was capable but increasingly costly and complex to operate for the traffic patterns and team size involved.

Services applied

SaaS PlatformsEdge ArchitectureAuth & SecurityCloud InfrastructureObservabilityAPI Gateways

What we built

  • Designed a shared data layer so SGS Analytics, SGS Quotes, SGS Workflows, SGS Advertise, and SGS Orders all read from and write to consistent, connected data — instead of duplicating records across separate tools.
  • Built Stellar AI and Stellar Bills as native modules within the same ecosystem, so AI-assisted work and billing sit alongside operational tools rather than bolted on separately.
  • Implemented SSO so users can move between the applications in the ecosystem under a single, secure identity — important as the number of connected tools grew.
  • Planned and executed a staged migration of the platform from AWS to Cloudflare Workers and edge infrastructure, moving traffic over incrementally to avoid downtime.
  • Set up observability (via New Relic and Cloudflare Analytics) and security tooling (Snyk, SonarCloud, SGS Security, SGS Scan) so the growing ecosystem stays monitored and auditable as it scales.
  • Established CI/CD and supporting tooling (SGS Docs, SGS Testing, GitHub-based workflows, DevHelm) so the team can ship changes across multiple connected applications safely.

The outcome

The result is a single, connected ecosystem rather than a patchwork of disconnected tools — with lower infrastructure overhead after the move to Cloudflare's edge network, and SSO that lets the team and their users move between applications without re-authenticating. The platform now supports the full operational surface of the business: from quoting and orders through to AI-assisted workflows and billing.
